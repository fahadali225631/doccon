Frequently Asked Questions

Why does the application display a notice when I upload an old .doc file?

Old binary formats (.doc deployed between 1997-2003) use proprietary compilation code trees. This privacy-focused tool parses files locally without network engines, meaning it exclusive renders structure layers from modern open-standard XML documents (.docx).

How can I transform my legacy .doc file into a compatible format?

Simply open your document inside the standard free Google Docs service or standard mobile Microsoft Word viewer interface, choose 'Save As', select the Word Document (.docx) checkbox option, and retry your process on our system.
